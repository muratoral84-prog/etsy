## 8. FAQ section for the listing

**Does this work on my phone?**
Yes — in the free Google Sheets or Microsoft Excel app, on iOS and Android.
The guide shows you how to add it to your home screen so logging is one tap.

**Do I need Microsoft Excel?**
No. A free Google account is enough. Upload the file to Google Sheets and
everything works, streaks included.

**Is this a subscription?**
No. You buy a file, the file is yours, and there is nothing to cancel.

**Can I start in the middle of the year?**
Yes. Type any Monday into the start-date cell and all 52 weeks re-date
themselves around it.

**How many habits can I track?**
Up to 10. Start with three.

**Is it printable?**
Yes — every tab is set up to print as one clean landscape page. Use the Light
workbook for printing.

**Are there macros?**
None. Nothing runs and no security warning will appear.
